# compos-site-app

Turn a live website into a compos list-and-detail app.

A community package for [compos](https://github.com/compos-dev). Install it from init.scm:

```scheme
(use-package 'site-app 'repo "compos-dev/compos-site-app" 'defer #t)
```

The apps ats and amazon live here too. Their autoload cookies put M-x ats and M-x amazon in the command list; each loads on first use.
